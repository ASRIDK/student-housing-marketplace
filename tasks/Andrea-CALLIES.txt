----------------------------
1. Design choices (write them down at the top of globals.css as a
   comment so others follow them):
     - one primary colour, one accent, grey scale
     - one font via next/font (e.g. Inter or Manrope)
     - one colour per city for CityBadge:
         Milan / Madrid / Geneva / Paris / Marseille
   Keep it clean and modern; the reference feeling is "Airbnb for
   students", not a corporate site.

2. Navbar (sticky top): logo/wordmark "StudentSwap" -> "/",
   links: Browse ("/"), Post an apartment ("/listings/new"),
   How it works ("/about"). Right side: "Log in" + "Sign up" buttons.
   On phone: hamburger button that opens a simple dropdown menu
   ("use client"). Highlight the active link (usePathname).
   For now the navbar always shows "Log in / Sign up"; Taoufik will
   later swap it for the user's name + "My listings" when logged in.
   Leave a // TODO(auth) comment there.

3. Footer: school name, the 5 cities as links to
   "/?city=Milan" etc., "Made by ... for the Data Science class 2026",

4. layout.tsx: <Navbar /> ... <main className="mx-auto max-w-6xl
   px-4 py-8">{children}</main> ... <Footer />. Set the metadata
   title template: "%s — StudentSwap".

5. CityBadge: <CityBadge city="Paris" /> -> small pill with the
   city colour. Export it; tell Alejandro and Leo when it's merged.

6. Login & Signup pages (UI only — no real login yet):

     signup: name, school email, password, confirm password
     login:  email, password

   match. Show errors under the fields. On submit: console.log the
   values and show "Not connected to the backend yet" — Taoufik
   wires it. Leave // TODO(auth). Link between the two pages
   ("Already have an account? Log in").

7. /about page: 3 short steps with icons (emoji is fine):
   "Post your apartment" -> "A student contacts you" -> "Hand over
   the keys". Plus the list of the 5 campuses/cities.
