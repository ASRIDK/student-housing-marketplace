YOUR GOAL
---------
When someone opens the website, they see every available apartment as
a grid of cards, and they can filter by city, maximum rent and
"available from" date. This is the most-visited page of the site, so
make it look good.

FILES YOU OWN (create these, don't touch others)
------------------------------------------------
   src/app/page.tsx                    the home page
   src/components/ListingCard.tsx      one card in the grid
   src/components/FilterBar.tsx        the filters at the top
   src/components/EmptyState.tsx       "No apartments match" message

WHAT TO BUILD — step by step
----------------------------
1. ListingCard  (start here, it's the easiest)
   Shows for one Listing: first photo (or a grey placeholder if
   photos is empty), city as a small badge, neighbourhood, rent +
   currency ("850 EUR / month"), rooms ("2 rooms" or "Studio"),
   "Available from <date>". The whole card is a <Link> to
   /listings/<id>. Cards look good in a grid of 3 on laptop, 1 on
   phone.

2. Home page grid
   In src/app/page.tsx import the mock listings from
   src/lib/mock-data.ts, keep only status === "active", and render a
   ListingCard for each in a responsive grid
   (grid-cols-1 sm:grid-cols-2 lg:grid-cols-3, gap-6).

3. FilterBar  ("use client")
   Controls: City dropdown (All / Milan / Madrid / Geneva / Paris /
   Marseille), Max rent (number input), Available from (date input),
   Reset button. Store the values in the URL, e.g.
   /?city=Paris&maxRent=900  using useSearchParams + useRouter
   (so the link is shareable). Remember to wrap it in <Suspense>.

4. Filtering logic
   In page.tsx read searchParams (it's a Promise — await it) and
   filter the listings before rendering. Sort newest first
   (createdAt). If nothing matches, show EmptyState.

5. Polish
   Show "12 apartments" count above the grid. Nice hover effect on
   cards. Page title "StudentSwap — find your next apartment".
